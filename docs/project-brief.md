# Project Brief

**Dust Trail** is a free, original Western-themed adventure game rendered
entirely in ASCII. The player takes the role of "Dust," a drifter in a
frontier town, moving through a top-down ASCII world, talking to the sheriff,
pursuing the outlaw, collecting loot, and saving progress.

**Primary user:** Players who enjoy turn-based, exploration-focused games with
a minimalist ASCII aesthetic, playable in a terminal or as a lightweight
desktop window.

**Problem it solves:** Provides a small, readable, hackable Western adventure
game with no commercial trademarks, no proprietary assets, and no network
requirement to play.

**Suite:** Standalone app in the Rust suite; shares the `crash-report` and
`update-check` suite crates.
