# Ticket T-006: Implement `Sprite` type (cells + depth + anchor)

## Objective
Define the `Sprite` type that holds the rasterised character grid, per-cell depth map, and footprint anchor.

## Target Files
- `apps/dust-trail/src/render/sprite.rs` (new)

## Acceptance Criteria
- [ ] `Sprite` struct with fields:
  - `key: ModelKey`
  - `width: usize`, `height: usize`
  - `cells: Vec<Vec<(char, Rgb, Rgb)>>` — grid of (char, fg, bg) per cell
  - `depth: Vec<Vec<f32>>` — per-cell depth matching `cells` dimensions
  - `anchor: (i32, i32)` — screen offset of sprite's origin (bottom-center by convention)
- [ ] Contract: `cells` and `depth` have identical dimensions; `anchor` defaults to (0, 0)
- [ ] Empty sprite: width=0, height=0, empty cells/depth (for degenerate models)
- [ ] Unit tests: cells/depth grids identical dimensions, anchor default (AC-005)
- [ ] CI passes: `cargo test --workspace -- render::sprite` (headless, no GUI)

## Blocking Dependencies
- T-001 (render module tree exists)

## Notes
- `Rgb` is a simple tuple struct or use `egui::Color32` converted to RGB components
- Per spec Section 5: `Sprite` includes per-cell depth for occlusion, not in `Cell`
- The `anchor` is the screen offset from the object's world position to the sprite's origin cell
