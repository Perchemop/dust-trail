# Ticket T-216: Release workflow - installer signing

## Objective
Update release workflow to sign installers for all platforms.

## Target Files
- `.github/workflows/release.yml`
- `release/signing.sh` (new)

## Acceptance Criteria
- [x] Windows: `signtool sign` with EV certificate (from GitHub Actions secret)
- [x] macOS: `codesign --deep --force --verify --verbose` with Developer ID (from secret)
- [x] Linux .deb: `dpkg-sig` with GPG key (from secret)
- [x] Linux .AppImage: `minisign -S` with private key (from secret)
- [x] All signing steps run in parallel per OS
- [x] Signing failure → workflow fails (no partial artefacts)
- [x] Signing scripts use only CI secrets (no local keys)

## Blocking Dependencies
- v2.0.0 release.yml

## Notes
- Secrets: `WINDOWS_SIGN_CERT`, `WINDOWS_SIGN_PASSWORD`, `APPLE_DEVELOPER_ID`, `APPLE_DEVELOPER_ID_PASSWORD`, `APPLE_TEAM_ID`, `GPG_PRIVATE_KEY`, `GPG_PASSPHRASE`, `MINISIGN_PRIVATE_KEY`
- macOS notarization handled in T-217
