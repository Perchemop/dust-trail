# Ticket T-007: Implement software rasteriser (project, fill, z-buffer, Lambertian)

## Objective
Implement the core software rasteriser that projects 3D primitives to screen space, fills covered pixels, writes to z-buffer, applies Lambertian shading, and converts luminance to glyphs.

## Target Files
- `apps/dust-trail/src/render/raster.rs` (new)

## Acceptance Criteria
- [ ] `Rasteriser` struct with `light_dir: (f32, f32, f32)`, `width: u32`, `height: u32`
- [ ] `Rasteriser::new(width, height)` and `with_light(dir)` builder
- [ ] `render(model: &ObjectModel, camera: &Camera) -> Sprite`:
  - Projects primitives using camera's fixed isometric projection (FR-017)
  - Fills every screen cell covered by primitive's footprint (FR-018)
  - Writes per-cell depth to z-buffer, keeps nearest depth per cell (FR-019)
  - Applies Lambertian shading: luminance = albedo × max(0, normal · light_dir) (FR-020)
  - Converts luminance to glyph via glyph ramp (FR-024)
  - Returns `Sprite` with cells, depth grid, anchor
- [ ] Deterministic: same model + camera → byte-identical Sprite (FR-021, AC-007)
- [ ] Empty model (no primitives) → 0×0 empty sprite, no panic (FR-022, AC-005)
- [ ] Zero-size raster (width or height = 0) → empty sprite, no panic (FR-023, AC-005)
- [ ] No `panic!`, `unwrap`, `expect` in public API (NFR-008)
- [ ] Unit tests: projection, fill, z-buffer nearest-wins, Lambertian shading monotonicity, determinism, empty model, zero-size raster (AC-005, AC-007)
- [ ] CI passes: `cargo test --workspace -- render::raster` (headless, no GUI)

## Blocking Dependencies

- T-004 (Camera)
- T-005 (Glyph ramp)
