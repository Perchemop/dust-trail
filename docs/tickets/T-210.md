# Ticket T-210: DebugCamera core types

## Objective
Add `gui/camera.rs` with `DebugCamera` struct, input handling, and view matrix.

## Target Files
- `apps/dust-trail/src/gui/camera.rs` (new)
- `apps/dust-trail/src/gui/mod.rs` (declare module)

## Acceptance Criteria
- [x] `DebugCamera::new()` with defaults (enabled=false, yaw=0, pitch=0, distance=default, isometric, toggle_key=Ctrl+Shift+C)
- [x] `handle_input(&mut self, ctx: &egui::Context) -> bool` processes:
  - Configured toggle key (default Ctrl+Shift+C) → toggle enabled
  - Mouse drag (when enabled) → yaw/pitch
  - Scroll (when enabled) → distance
  - 'P' (when enabled) → toggle isometric/perspective
  - 'R' (when enabled) → reset to defaults
- [x] Returns `true` when input consumed (blocks GUI processing)
- [x] `view_matrix()` returns 4×4 matrix for rasteriser
- [x] `project(wx, wy, wz)` replaces fixed camera when enabled
- [x] Pitch clamped to -89..89°, distance clamped to reasonable bounds
- [x] Toggle key configurable in Settings (KeyBinding type)
- [x] Headless unit tests pass (with egui headless)

## Blocking Dependencies
- v2.0.0 complete

## Notes
- Debug camera is GUI-only (egui imports allowed here)
- Input handling via egui's `ctx.input()`
- View matrix: standard look-at with orbit around anchor
- Perspective projection: FOV ~60°, aspect from viewport
