# Ticket T-217: Release workflow - macOS notarization

## Objective
Add macOS notarization step (submit, poll, wait, staple) to release workflow.

## Target Files
- `.github/workflows/release.yml`

## Acceptance Criteria
- [x] After codesign: `xcrun notarytool submit --wait --apple-id --team-id --password`
- [x] Poll notarization status with 20-minute timeout
- [x] On success: `xcrun stapler staple` the DMG
- [x] On timeout: attach unsigned DMG with clear warning label in release notes; log re-sign task for next patch
- [x] Notarization runs after codesign, before artefact upload
- [x] Uses GitHub Actions secrets: `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_PASSWORD`

## Blocking Dependencies
- T-216 (signing)

## Notes
- Notarization can take 5-20 minutes
- Use `xcrun notarytool` (modern, not deprecated `altool`)
- Stapling ensures offline verification works
- Fallback: if notarization fails, workflow fails (no unsigned DMG released)
