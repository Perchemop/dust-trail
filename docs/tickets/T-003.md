# Ticket T-003: Implement `ObjectModel`, `ModelRegistry`, placeholder model

## Objective
Define the `ObjectModel` type and `ModelRegistry` that maps game entity kinds to models, with graceful fallback to a placeholder for unknown kinds.

## Target Files
- `apps/dust-trail/src/render/model.rs` (new)

## Acceptance Criteria
- [ ] `ObjectModel` struct with: `key: ModelKey`, `name: String`, `primitives: Vec<Primitive>`, `bounding_box: BoundingBox`, `draw_key: DrawKey`
- [ ] `ModelKey` type alias: `&'static str`
- [ ] `BoundingBox` struct with `min: (f32, f32, f32)`, `max: (f32, f32, f32)`
- [ ] `ModelRegistry` with methods: `new()`, `register(kind, model)`, `model_for(kind)`, `placeholder()`
- [ ] `model_for` returns placeholder for unknown kinds — **never panics** (FR-015, AC-009)
- [ ] Deterministic lookup: same kind → same model (FR-016)
- [ ] Register models for all entity kinds: tree, shrub, cactus, rock, water, barn, player, sheriff, deputy, outlaw, loot, horse (FR-013)
- [ ] Unit tests: registry lookup returns placeholder for unknown kind; deterministic lookup (AC-009)
- [ ] CI passes: `cargo test --workspace -- render::model` (headless, no GUI)

## Blocking Dependencies
- T-002 (Primitive types exist)

## Notes
- Per spec Section 5: `model_for` on unknown kind returns `&placeholder` (single-cell '?' sprite), logs at debug level, never panics
- Per NFR-008: no crash discipline
