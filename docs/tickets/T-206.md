# Ticket T-206: TimeOfDay system

## Objective
Add `domain/time.rs` with `TimeOfDay` struct and light calculation from turn count.

## Target Files
- `apps/dust-trail/src/domain/time.rs` (new)
- `apps/dust-trail/src/domain/mod.rs` (declare module)

## Acceptance Criteria
- [x] `TimeOfDay::new(turns_per_hour, night_ambient_fill)` constructor (night_ambient_fill default 0.15)
- [x] `advance_turn()` increments turn_count, wraps at `turns_per_day`
- [x] `hour()` returns 0..23
- [x] `light_elevation_deg()` returns -90..90 (sin wave)
- [x] `light_azimuth_deg()` returns 0..360
- [x] `light_intensity()` returns 0.15..1.15 (ambient + directional)
- [x] `ambient_fill()` returns 0.0 (day) or configured night_ambient_fill (night)
- [x] `light_dir_normalized()` returns (x,y,z) for Rasteriser
- [x] `is_night()` returns elevation < 0
- [x] `sun_moon_glyph()` returns '☀' or '☽'
- [x] Default: 10 turns/hour, 240 turns/day, night_ambient_fill = 0.15
- [x] Deterministic: same turn_count → same outputs
- [x] Headless unit tests pass (including night contrast verification)

## Blocking Dependencies
- v2.0.0 complete

## Notes
- Formula: elevation = sin(turn/240 * 2π) * 90°
- Intensity = max(0, sin(elevation)) + 0.15
- Ambient = 0.15 when elevation < 0, else 0.0
- No egui/eframe imports (NFR-207)
- Saturating arithmetic for turn counter (NFR-209)
