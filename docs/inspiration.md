# Inspiration

Behaviour-level inspiration for the Western / frontier adventure genre. All
entries are original behavioural summaries with public-source URLs; no
proprietary source, assets, or trade dress is copied (guide Part I §2.2,
Part II §27.2).

| Capability | Behaviour summary | Source URL |
|------------|-------------------|------------|
| Top-down ASCII world | A grid of tile glyphs representing ground, walls, water, trees, buildings, with a player avatar and NPCs. | General genre convention (roguelike / ASCII games) |
| Turn-based movement | Player moves one tile per input; NPCs act after each player turn. | General turn-based game convention |
| NPC interaction | Pressing a key adjacent to an NPC displays a dialogue line. | General adventure-game convention |
| Item collection | Walking onto an item tile collects it and updates score. | General game convention |

**Note:** "Red Dead Redemption" and related marks are trademarks of Rockstar
Games. Dust Trail does not use them; the world, art style, name, and mechanics
are original (see `DECISIONS.md`).
