# /grill-me — interrogation phase (guide §5.6.3)

Read-only exploration. Do not write code or implementation plans until every ambiguity is resolved.

- Ask targeted questions one by one, providing a recommended answer for each based on existing codebase patterns.
- Goal: alignment on edge cases, data structures, and failure modes.
- Clean-room check: if the answer would come from a proprietary source, stop and route through the §2.3 human gate.
