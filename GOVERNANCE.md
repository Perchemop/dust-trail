# Governance

Dust Trail is maintained under the clean-room build process in `~/guide.md`
(never committed to the repo). The maintainer:

* Sets goals, priorities, and "does this work / feel right?"
* Reviews and merges pull requests once CI is green.
* Maintains `ROADMAP.md`, `CHANGELOG.md`, `DECISIONS.md`, and this file.

Responses to issues/PRs are targeted within seven days, maintained in spare
time — a firm commitment, not a guarantee of an instant fix (guide II.23).

## Git identity

Every git action is authored as `Dust Trail Dev <dev@example.com>` (guide
II.26.7). GitHub PR/merge authorship follows the pushing account.
