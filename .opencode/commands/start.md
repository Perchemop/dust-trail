# /start Command

Initialize the OpenCode Game Studios workflow for the Dust Trail project.

## Usage

```
/start
```

## Description

Initializes the OpenCode Game Studios workflow by:
1. Checking the project structure
2. Validating the configuration
3. Setting up the agent environment
4. Providing next steps

## Steps

1. **Check Project Structure**: Verify that the project has the required directory structure.
2. **Validate Configuration**: Verify that the AGENTS.md and opencode.json are configured correctly.
3. **Setup Environment**: Set up the agent environment with the correct context.
4. **Next Steps**: Provide next steps for the user.

## Example Output

```
🎮 OpenCode Game Studios - Initialization

✅ Project structure verified
✅ Configuration validated
✅ Agent environment ready

Next steps:
1. Run /concept-brainstorm to start game design
2. Run /setup-engine to configure the game engine
3. Run /implement to start feature development
```
